# Business AI Infrastructure Assessment Framework Options

Each option begins with function and seniority so the language can adapt to the visitor's actual operating context. None of the options asks visitors to know what outcome they should want.

## Option 1 Observable Operating Reality

This preserves the strongest part of the current diagnostic and contextualizes it.

The assessment asks what happens today when work begins, useful context is created, rules or approvals appear, similar work is repeated, leadership intervenes, an exception occurs, and someone new joins.

Each question describes observable behavior rather than an aspiration.

The result identifies the current maturity level, the weakest operating dimension, and the next structural move.

This is the recommended near-term option because it retains the meaning of the existing seven questions while making them easier to recognize.

## Option 2 Capability Evidence Ladder

This tests whether evidence exists for each level of the maturity model.

The assessment examines individual AI use, managed AI work, reusable capability, cross-functional access, embedded governance, and compounding strategic learning.

Each question asks for concrete evidence such as how often work completes without intervention, whether successful work is reused, and whether another function can access the capability safely.

The result identifies the highest level supported by evidence rather than averaging aspiration across questions.

This option is especially useful for transformation leaders who need a defensible maturity score.

## Option 3 Friction and Flow Diagnostic

This infers maturity by locating where intelligence stops moving.

The assessment examines missing context, repeated setup, approval delays, expert bottlenecks, inconsistent execution, weak exception learning, and function boundaries.

Visitors answer what normally happens when work encounters each source of friction.

The result identifies the dominant bottleneck and the maturity move that would remove it.

This option feels practical and problem-led, but it describes the constraint more strongly than the overall maturity level.

## Option 4 Autonomy and Reuse Matrix

This scores the organization on two independent axes.

The first axis measures how much bounded work AI can complete under appropriate human direction.

The second axis measures how far successful capability travels beyond the person or team that created it.

Governance questions determine whether apparent autonomy and reuse are dependable or fragile.

The result places the visitor in a simple matrix and recommends the weaker axis as the next move.

This option creates the clearest visual result, but it is less directly aligned with the five-level public narrative.

## Recommended direction

Use Observable Operating Reality for the public evaluation.

Add Capability Evidence Ladder logic behind the scoring so a higher level is awarded only when the required evidence is present.

Keep the existing seven dimensions, ask function and seniority first, and rewrite only the framing and examples so an individual contributor sees their work, a manager sees their team, and an executive sees the organization.
