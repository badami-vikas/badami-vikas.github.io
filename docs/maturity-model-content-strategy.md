# Maturity Model Content Strategy

## The job of the page

The page helps a visitor recognize their current operating reality, understand the next shift, and see how Zazoo can help them make it.

## The narrative spine

The model is a journey rather than five independent definitions.

1. Ask turns AI into useful help for an individual task
2. Direct moves an individual from asking AI to managing bounded AI work
3. Multiply turns successful work into reusable organizational capability
4. Extend makes governed capability available beyond its original function
5. Reinvent uses compounding intelligence to create new value and competitive advantage

Each step changes where the work lives. It moves from an individual interaction to a team workflow, then to organizational memory, shared capability, and finally the operating model itself.

## The three content states

General mode explains the structural shift without an example.

Function mode applies the same structural shift to a selected business function so visitors can see what changes in their own work.

Without Zazoo mode explains the LLM, automation, knowledge, integration, governance, and monitoring stack required to create the outcome.

Zazoo mode replaces that stack explanation with Zazoo's role in the same transition. It does not append a separate product pitch.

## The information carried by every level

Every level communicates what the system does, what it scales, and how progress is measured.

The active level is written as one cohesive set of natural sentence bullets. Product mechanics appear only when they make the operating shift easier to understand.

## Interaction principles

The five-stage journey remains visible at all times so content changes stay comparable.

General is the default function.

The visitor can select Human Resources, Finance, Sales, Marketing, Operations, or Engineering.

The Zazoo switch morphs the current content in place and preserves the selected function and level.

The interface supports mouse, touch, keyboard navigation, and reduced motion.

## Voice rules

The copy begins with what changes for the visitor.

The language stays concrete, organizational, and free of unnecessary architecture terms.

Every bullet is a naturally flowing sentence.

Visitor-facing copy contains no colons.

Claims describe intended capability and outcomes without promising unsupported results.
